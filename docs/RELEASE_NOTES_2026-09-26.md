# リリースノート — 2026-09-26

## 演出の追加・強化

- オリジナル版から153種類の演出（文字PV系50・キネティック51・ホラー52）と、ホラー向け3スタイルを追加。
- 追加演出を既存テーマの選定候補へ反映し、「ホラー」テーマを追加。
- 文字PV系・キネティックは初期ON、ホラーは初期OFF。ホラーテーマでおまかせを実行するとホラー演出も有効になります。

## 歌詞編集

- 歌詞の表示エリアを画面外まで移動・拡大できるように変更（幅・高さは最大400％）。
- `｜　　　　｜` のように全角の縦線で空白を囲み、文字を表示せず演出だけを適用する「空の歌詞」を追加。
- `{- … -}` で囲んだ歌詞を順に残しながら、歌詞同士の重なりを避ける記法を追加。詳細 → 手法で回避の強度を調整できます。
- 歌詞欄の下に入力補助ボタンを追加：カット／改行／強調／抑制／1シーン／重ねず1シーン／空の歌詞。
- 入力補助はカーソル位置への挿入・選択範囲への適用に対応し、1クリック単位でアンドゥ／リドゥできます。
- 「空の歌詞」は選択中の文字を半角／全角スペースに置き換え、挿入後は次の行へカーソルを移動します。未選択時は全角スペース4つを挿入します。
- 注釈記法の説明に、対応する演出でのみ小さな文字が表示されることを明記。

## 演出のコピー・ペースト

- カットの操作欄・タイムライン・プレビュー枠に、演出のコピー／ペースト操作を追加。
- 歌詞同士、前景・背景素材同士で演出をコピーできます。
- 歌詞はフォント・配色・詳細パラメータ・描画用乱数・付随エフェクトも複製。本文・表示エリア・開始時刻は貼り付け先を維持します。
- 貼り付け先の長さに応じて登場・退場時間やイベントを制限します。
- ペースト後に再抽選しても演出が変化しない問題を修正。全体の再抽選ではロック済みの行を維持します。
- コピー／ペースト後の再抽選もアンドゥに対応。

## プレビュー・背景

- プレビュー下に「アイテム枠表示」を追加（初期ON）。前景・歌詞・背景の枠と操作アイコンを表示します。再生中は操作できません。
- 背景の素材選択に「前景をコピー（素材のみ）」「前景をコピー（演出含む）」「歌詞のコピー」を追加。
- 同じフレームの前景・歌詞を参照し、その上に背景側の演出を重ねられます。コピー元の編集は即時反映されます。
- 詳細 → 背景に「歌詞の背景演出も適用」を追加（初期ON）。

## プロジェクト管理

- 「設定のみ書き出し」「設定のみ読み込み」を追加。
- テーマ・演出・色・フォント・出力設定などを、歌詞・画像・動画・音声・カットを含めずに保存できます。取り込んだフォントファイルは含まれます。
- 設定用ファイルだけでなく、通常のプロジェクトファイルからも設定だけを読み込めます。現在の歌詞・素材・カット構成・同期設定は維持します。
- 設定読み込みはアンドゥに対応。

日本語・英語UIに対応し、ブラウザ版とCEP配布物を更新しています。
